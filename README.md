# AI Study Assistant

## Domain
Education

## Problem Statement
Students spend significant time searching for learning materials and understanding difficult concepts.

## Proposed Solution
AI Study Assistant is an intelligent learning platform that summarizes notes, answers academic questions, and generates quizzes to improve learning.

## Features
- PDF Upload
- Notes Summarization
- AI Question Answering
- Quiz Generation
- Personalized Learning (Future)

## Tech Stack
- Frontend: HTML, CSS, JavaScript (React in future)
- Backend: Python (FastAPI)
- AI: Gemini API
- Database: MongoDB/Firebase (Future)
